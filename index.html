阵容码使用说明
Team Planner 阵容码由 Set 标识和棋子 ID 组成。棋局不会控制游戏客户端；进入 Team Planner 后，请自行粘贴代码。棋子 ID 映射来自公开 Set 数据，遇到新补丁或新 Set 时请重新载入。
